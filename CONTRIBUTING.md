# Contributing to ReconForge v3

Thank you for your interest in contributing to **ReconForge v3**!

## How to Contribute
1. **Fork the Repository** on GitHub: `https://github.com/pratik-khairnar-sec/ReconForge-v3`
2. **Create a Feature Branch** (`git checkout -b feature/amazing-feature`)
3. **Commit your Changes** (`git commit -m 'Add new dorks or recon methodology phase'`)
4. **Push to the Branch** (`git push origin feature/amazing-feature`)
5. **Open a Pull Request**

## Guidelines
- Ensure that the application remains **100% offline and standalone** in `index.html`.
- Maintain the **Ergonomic Eye Comfort UI standards** (clean contrast, zero eye strain, no vibrating text shadows).
- All offensive commands must adhere to strict authorized security testing and ethical Bug Bounty / VAPT practices.

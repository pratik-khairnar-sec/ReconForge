## 🌟 Executive Summary

**ReconForge v5** is an elite, **100% client-side, zero-dependency, offline reconnaissance operating system and offensive intelligence workstation** engineered specifically for Lead VAPT Engineers, Professional Bug Bounty Hunters, and Red Team Operators.

Authored and curated by **[Pratik Khairnar (@pratik-khairnar-sec)](https://github.com/pratik-khairnar-sec)**, ReconForge v5 consolidates enterprise-grade offensive security methodology into an ultra-fast, single-dashboard command workstation. It unifies **30 comprehensive reconnaissance phases**, **135 sequential methodology steps**, exactly **53,077 globally deduplicated search queries**, an **Automated VAPT & Continuous Security Audit Command Deck**, multi-target tool-major execution engines, dual-channel **Telegram bot reporting**, and an **OLED Red Team tactical UI**.

Everything operates entirely inside the browser using standard web APIs—**no Node.js installation required, no Python runtime needed, no external API keys forced, and zero telemetry leaving your machine**.

## 🎯 Core Architecture & Innovations

### 1. Tactical Red Team C2 Header & DEFCON Engine
ReconForge v5 features a specialized two-row tactical command header:
- **Terminal Identity Prompt**: `root@reconforge:[RED-TEAM]#` with live connection pulse indicator.
- **DEFCON Kinetic Toggles**:
  - `DEFCON 1 (KINETIC)`: Unconstrained scanning (100 threads, 300 rps) for authorized external infrastructure testing.
  - `DEFCON 2 (TARGETED)`: Balanced scanning (50 threads, 150 rps) calibrated to avoid WAF rate-limit triggers.
  - `DEFCON 3 (STEALTH)`: Low-and-slow reconnaissance (25 threads, 50 rps) for evasion and sensitive enterprise targets.
- **Audio Feedback Engine (SFX)**: Web Audio synthesizer generating subtle tactical mechanical audio clicks upon command execution and button toggles.

### 2. Automated VAPT & Continuous Security Audit Command Deck
Bypasses manual repetitive probing with 6 fully scripted autonomous frameworks:
1. **FW-01: Autonomous EASM & Headless DOM Crawling**: Chained `subfinder` + `dnsx` + `katana -headless` with live DOM rendering and automatic `subzy` dangling CNAME verification.
2. **FW-02: Autonomous API Contract-Driven Property Fuzzing**: Runs `schemathesis run` with stateful state-machine testing and hyphenated header injection against OpenAPI / Swagger schemas.
3. **FW-03: Autonomous HTTP/2 Single-Packet Race Condition Engine**: Parallelized `ffuf` multi-worker cluster blasting synchronised requests within a single microsecond window.
4. **FW-04: Autonomous Dual-Identity BOLA/BFLA Matrix Replay**: Automated session token swapping testing multi-tenant object permissions across all enumerated API routes.
5. **FW-05: Autonomous Secret Intelligence with Live Key Verification**: Executes `trufflehog filesystem` and `git` secret extraction with live cloud-provider signature verification.
6. **FW-06: Autonomous AI/LLM & Multi-Agent Security Fuzzing**: Runs Microsoft `PyRIT` multi-turn adversarial red teaming against conversational chatbots and RAG interfaces.

### 3. 53,077 Mega Dork Intelligence Vault
- **In-Memory Client-Side Engine**: Performs sub-millisecond regex and substring searches across 53,077 curated intelligence dorks directly in browser RAM.
- **Categorized Vault**:
  - `🔥 Top 1% Elite Vault`: 2,915 P1/P2 critical exploit dorks.
  - `🔑 Passwords & .env`: 3,794 environment and database credential leaks.
  - `🚪 Admin Panels`: 3,647 authentication and SSO gateways.
  - `🐙 GitHub Secrets`: 1,447 developer token queries.
  - `💉 SQLi & Injection`: 26,185 high-yield parameter triggers.
  - `📚 GHDB Archive`: 12,112 Exploit-DB vulnerability signatures.
  - `☁ Cloud Storage`: 516 open S3, Azure Blob, and GCP bucket probes.
  - `⚡ APIs & Swagger`: 297 OpenAPI and GraphQL discovery queries.
  - `🌐 Google-Dorking.com`: 1,014 curated OSINT vectors.
  - Additional specialized categories covering Shodan, Actuators, Backups, Paid BBPs, and Security.txt policies.

### 4. 5 Operational Playbook Profiles
Instantly tailors the methodology view and active phase visibility:
- **Full Scope (30 Phases / 135 Steps)**: Comprehensive end-to-end vulnerability assessment.
- **Web & API (12 Phases)**: Focused on OWASP Top 10, GraphQL, JWT, and API business logic.
- **Cloud & Infra (9 Phases)**: Dedicated to network mapping, port scanning, origin IP discovery, and cloud storage audits.
- **Silent Stealth (5 Phases)**: Purely passive reconnaissance without direct packet transmission to the target.
- **Automated VAPT (12 Phases)**: Orchestrated CI/CD continuous testing using automated tool chains.

### 5. Dual-Channel Telegram Dispatch & 30-Phase HTML Report
- **Milestone Snapshot Alerts**: Transmits real-time markdown notifications with phase completion statistics to private Telegram channels.
- **Full Executive Report**: Compiles completed phase notes, findings, and verified PoCs into a self-contained, offline HTML report sent directly to your Telegram chat.

### 6. Bug Bounty Engagement Workspace & Active Timer
- **Multi-Program Workspaces**: Segregates findings and targets per program without cross-contamination.
- **Active Stopwatch Timer**: Integrated into the header toolbar for precise tracking of billable engagement hours, persisting across reloads.

## 🚀 Quick Start & Installation

### Option 1: Direct File Launch (No Installation Needed)
ReconForge v5 is completely self-contained within `index.html`:
```bash
git clone https://github.com/pratik-khairnar-sec/ReconForge.git
cd ReconForge
# Double click index.html or launch via your default browser:
start index.html       # Windows
open index.html        # macOS
xdg-open index.html    # Linux
```

### Option 2: Local HTTP Server (Recommended for Telegram & Live Probing)
```bash
cd ReconForge
python3 -m http.server 8080
# Open http://localhost:8080 in Chrome, Brave, or Firefox
```

### Option 3: Automated Tool Arsenal Setup
Install all underlying CLI tools on Kali Linux or Ubuntu WSL:
```bash
chmod +x install_reconforge_tools.sh
./install_reconforge_tools.sh
```

## 💼 Practical Workflows & Field Scenarios

### Workflow 1: Single Target In-Depth Assessment
1. Launch ReconForge v5 in your browser.
2. In the top target input box, enter `target.com` and click **"⚡ APPLY SCOPE TO ALL 30 PHASES"** (or press `Ctrl+Enter`).
3. Click **"⏱ 00:00:00"** to initiate your engagement time tracking.
4. Set the operational DEFCON level (e.g., **DEFCON 2: TARGETED**).
5. Switch to the **Automated VAPT** playbook profile or progress through **Phases 01 through 08** sequentially:
   - Copy each pre-formatted tool command.
   - Run the command in your terminal.
   - Check the phase checklist box upon completion.
6. When an issue is discovered, open **"📋 Report Gen"** from the top toolbar, fill in the PoC details, and download an instant markdown disclosure report.

### Workflow 2: Wildcard Scope Multi-Target Ingestion
1. Copy a wildcard list from your bounty program brief:
   ```text
   *.target.com
   *.api.target.com
   *.internal-service.io
   ```
2. Paste the list directly into the target textarea (ReconForge automatically normalizes wildcards and extracts distinct hostnames).
3. Click **"⚡ APPLY SCOPE TO ALL 30 PHASES"**.
4. Open **"🚀 Script Gen"** from the top toolbar, select your required phases, and download `recon_pipeline.sh`.
5. Execute on your remote VPS:
   ```bash
   chmod +x recon_pipeline.sh && ./recon_pipeline.sh
   ```
